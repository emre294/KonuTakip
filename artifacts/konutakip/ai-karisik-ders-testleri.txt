### 1. Soru Çözümü

2. Zaman = mesafe ÷ toplam hız = 240 ÷ 100 = 2,4 saat = 2 saat 24 dakika.

### 2. Soru Çözümü
1. Başlangıçtaki tuz miktarı = 0,12 × 500 = 60 g.
2. x g saf tuz eklendiğinde yeni tuz miktarı = 60 + x, yeni hacim = 500 + x ml.
3. (60 + x) ÷ (500 + x) = 0,20 denklemini kur.
4. 60 + x = 0,20·(500 + x) → 60 + x = 100 + 0,20x → 0,80x = 40.
5. x = 40 ÷ 0,80 = 50 g.

### 3. Soru Çözümü
1. Hızlı işçi hızı = 1/8 iş/gün, yavaş işçi hızı = 1/12 iş/gün.
2. Birlikteki hız = 1/8 + 1/12 = 5/24 iş/gün.
3. 3 gün çalışınca yapılan iş = 3 × 5/24 = 5/8 iş.
4. Kalan iş = 1 – 5/8 = 3/8 iş.
5. Hızlı işçi tek başına 1/8 iş/gün hızla çalıştığından, 3/8 işi bitirmek için (3/8) ÷ (1/8) = 3 gün gerekir.

### 4. Soru Çözümü
1. İndirimli fiyat = 0,90 L (L = liste fiyatı).
2. Satış fiyatı = 1,25 × (0,90 L) = 1,125 L.
3. Satış fiyatı aynı zamanda maliyet + %25 kar = 150 + 0,25·(0,90 L) = 150 + 0,225 L.
4. 1,125 L = 150 + 0,225 L → 0,9 L = 150 → L = 150 ÷ 0,9 = 166,66… TL.
5. En yakın tam TL’ye yuvarlandığında L ≈ 167 TL.

### 5. Soru Çözümü

3. (a + b)² = a² + b² + 2ab → 17² = 169 + 2ab → 289 = 169 + 2ab → ab = 60.
